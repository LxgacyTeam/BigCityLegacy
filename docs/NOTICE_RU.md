BigCityLegacy предназначен исключительно для использования с копией Steam-версии игры, которую пользователь получил законным путем и имеет право использовать.

Официальные версии BigCityLegacy могут проверять целостность и версию отдельных локальных игровых файлов, в том числе с использованием криптографических хешей. Такая проверка предназначена только для определения совместимости и выявления измененных или неподдерживаемых файлов.

## Устаревший AlwaysOnline-механизм

Поддерживаемая ПК-версия игры содержит устаревшую зависимость от внешнего AlwaysOnline-сервиса, при которой клиент отправляет простой сетевой запрос и ожидает ответ о доступности сервиса. Этот механизм сам по себе не выполняет аутентификацию пользователя, проверку Steam-лицензии, проверку внутриигровых покупок или выдачу пользовательской сессии.

После прекращения работы соответствующего сервиса отсутствие ответа препятствует запуску игры, включая локальные игровые режимы.

BigCityLegacy может изменять это поведение в целях совместимости с прекращенной версией клиента и восстановления возможности ее запуска без несуществующей сетевой зависимости.

Данная функциональность не предназначена для обхода систем аутентификации, лицензирования, DRM, проверки покупок или иных механизмов контроля доступа.

## Сетевой функционал

BigCityLegacy может предоставлять независимо реализованную сетевую инфраструктуру совместимости для прекращенной ПК-версии игры.
