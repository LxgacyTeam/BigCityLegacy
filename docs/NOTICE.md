## Obsolete AlwaysOnline Mechanism

The supported PC release contains an obsolete dependency on an external AlwaysOnline service under which the client sends a simple network request and expects a service-availability response. This mechanism does not itself authenticate the user, verify a Steam license, validate in-game purchases, or issue an authenticated user session.

Following discontinuation of that service, the absence of a response prevents the client from starting, including access to local gameplay modes.

BigCityLegacy may alter this behavior for compatibility with the discontinued client and to restore its ability to start without the unavailable network dependency.

This functionality is not intended to bypass authentication, licensing, DRM, purchase verification, or other access-control mechanisms.

## Network Functionality

BigCityLegacy may provide independently implemented compatible network infrastructure for the discontinued PC version of the game.
