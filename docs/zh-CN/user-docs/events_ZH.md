# 在线活动

**在线活动**是运行 `Race`、`CS` 或 `CS_Sur` 模式的服务器定期启动的活动。根据模式不同，它们可以是竞速赛道，也可以是警匪对抗的枪战场地。活动数据库由游戏客户端从服务器加载，游戏本身不保存预制赛道和场地。因此，原版赛道和场地已永久丢失。

为此，模组实现了从 JSON 文件加载自定义活动数据库的机制，使手动创建活动成为可能。

默认情况下，服务器从 `BigCityLegacy/Events.json` 加载活动。请参阅文件模板。

目前，模组仅附带少量现成活动，作为创建新活动的模板。计划近期提供更大的数据库，并随模组一起分发，尽可能改善普通玩家的体验。如果你愿意协助创建活动并提交作品，请将其发送到 Discussions 区的相应主题。

# 在线竞速：创建赛道

创建在线竞速活动，就是通过在地图上放置检查点来创建赛道。地图上的点坐标可通过 Point Tool v2 获取。详见下文相关章节。

**数据库中的竞速模板如下：**

```json
    {
      "mode": "Race",
      "name": "airport_01",
      "displayName": "Airport Circuit Race 01",
      "isSprint": false,
      "laps": 3,
      "useRespawn": true,
      "start": [
        { "x": -1642.374, "y": -23.585, "z": 183.954, "yaw": 183.525 },
        { "x": -1638.155, "y": -23.044, "z": 184.996, "yaw": 177.613 },
        { "x": -1647.588, "y": -23.197, "z": 185.731, "yaw": 176.502 },
        { "x": -1647.714, "y": -23.136, "z": 192.009, "yaw": 176.41 },
        { "x": -1642.523, "y": -23.136, "z": 192.331, "yaw": 178.945 },
        { "x": -1637.525, "y": -23.136, "z": 192.426, "yaw": 178.593 }
      ],
      "points": [
        { "x": -1639.268, "y": -23.605, "z": 103.205, "yaw": 175.679 },
        { "x": -1534.495, "y": -23.357, "z": 97.345, "yaw": 90.49 },
        { "x": -1422.056, "y": -23.575, "z": 95.94, "yaw": 90.569 },
        { "x": -1313.92, "y": -23.386, "z": 95.309, "yaw": 90.306 },
        { "x": -1211.561, "y": -23.275, "z": 176.372, "yaw": 41.478 },
        { "x": -1348.206, "y": -23.156, "z": 183.326, "yaw": 270.348 },
        { "x": -1464.071, "y": -23.439, "z": 183.758, "yaw": 270.077 },
        { "x": -1605.617, "y": -23.363, "z": 183.96, "yaw": 270.518 }
      ]
    }
```

**竞速字段：**

`mode` - 活动模式。竞速活动使用 `Race`。

`name` - 数据库中唯一的竞速活动名称。

`displayName` - 显示的竞速活动名称。

`isSprint` - 将竞速类型设置为冲刺赛（Sprint）。

`laps` - 比赛圈数。如果设为 `0`，圈数将随机选择为 1 或 2。

`useRespawn` - 是否允许玩家在最后一个检查点重生。

`start` - 起点数组。点的数量决定最大参赛人数。数组中的点顺序也与参赛者顺序对应。例如，第三位参赛者会在第三个起点生成。

`points` - 按顺序排列的检查点数组。如果指定多圈比赛，游戏会自动复制检查点。

# 警匪对抗：创建场地

为警匪对抗创建场地（即活动区域）非常简单，只需指定玩家生成点。点的数量等于玩家数量。游戏会根据各点之间的距离自动确定区域半径。

游戏中的警匪对抗有两个变体：CS 和 CS_Sur，后者也称为生存模式（Survival）。

`CS` - 两队之间的团队死斗。

`CS_Sur` - 所有玩家各自为战的自由混战死斗。

**数据库中的 CS 场地模板如下：**

```json
    {
      "mode": "CS",
      "name": "CopsVsBandits_01",
      "displayName": "CopsVsBandits 01",
      "counter": [
        { "x": -1634.599, "y": 1.314, "z": 2586.105, "yaw": 335.101 }
      ],
      "terror": [
        { "x": -1603.904, "y": 1.082, "z": 2623.952, "yaw": 345.323 }
      ]
    }
```

在这里，必须在 `counter` 和 `terror` 数组中分别指定各队的点。两队的点数必须相等。

---

**数据库中的 CS_Sur 场地模板如下：**

```json
    {
      "mode": "CS_Sur",
      "name": "Survival_01",
      "displayName": "Survival 01",
      "start": [
        { "x": -1634.599, "y": 1.314, "z": 2586.105, "yaw": 335.101 },
        { "x": -1603.904, "y": 1.082, "z": 2623.952, "yaw": 345.323 }
      ]
    }
```

在这里，只需在 `start` 数组中指定玩家生成点。

其余字段与竞速活动中介绍的字段相同：

`mode` - 活动模式：`CS` 或 `CS_Sur`。

`name` - 数据库中唯一的场地名称。

`displayName` - 显示的场地名称。

# Point Tool v2

Point Tool v2 用于确定地图上的点坐标。它可以将坐标数组直接保存到文件中，方便之后复制到配置中。

**主要功能：**

* 根据相机或玩家位置获取地图上的点坐标。
* 将坐标数组保存到文件。
* 在地图上显示可视化或交互式标记。
* 将玩家传送到指定坐标或相机位置。
* 逐个删除已保存的点，或一次清除所有点。

该工具从游戏设置中启动。

**共有三个快捷键：**

`Z` - 将当前相机坐标写入 `BigCityLegacy/pos_out.txt`。坐标按列表格式写入，方便复制到 JSON 中。每次重新启动游戏时都会清空该文件，因此请记得在游戏仍在运行时复制坐标。

`X` - 从文件中删除最后一个坐标。

`F9` - 将当前坐标复制到剪贴板。

为了方便保存坐标，建议使用通过 **F** 键开启的自由相机在地图上飞行，并记录坐标。
