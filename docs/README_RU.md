# BigCityLegacy

BepInEx плагин для Steam-версии игры **MadOut2 BigCityOnline**, полностью восстанавливающий онлайн и офлайн функционал.

#### Подробная информация о возможностях мода, запуске и настройке сервера находится в разделе Wiki

## Ключевые возможности

- Запуск своего игрового сервера с гибкой настройкой и администрированием
- Поддержка всех онлайн-режимов (FreeRoam, RP, Гонки, Копы против Бандитов)
- Возможность создания своих трасс и локаций для онлайн-гонок и копов против бандитов
- Дополнительные настройки и горячие клавиши (см. Wiki)

## Совместимость

Полностью поддерживается **только последняя Steam версия игры** `9.4`

Для более ранних версий (`4.9 - 9.2`) доступен режим совместимости (Compatibility Mode), обеспечивающий только офлайн функционал. На данный момент режим совместимости не гарантирует полную и стабильную работу ранних версий игры.

## Установка

* Скачайте посделнюю **оригинальную** версию игры из Steam *(модифицированные сборки игры **не поддерживаются**)*
* Установите BepInEx 5 в папку с игрой и запустите игру 1 раз
* Скачайте zip файл из раздела Releases и распакуйте в корневую папку игры

## Сборка

**Требования:**

- MadOut2 9.4 с установленным BepInEx 5
- .NET SDK

**Процесс сборки:**

1. Установите BepInEx 5 в папку с игрой и запустите игру 1 раз.
2. Клонируйте и соберите проект, указав **абсолютный путь** к корневой папке игры:

```bat
git clone --recurse-submodules https://github.com/LxgacyTeam/BigCityLegacy.git
cd BigCityLegacy
dotnet build -c Release -p:GameDir="path\to\game\dir" -p:CopyToPlugins=true
```

[!NOTE]
При открытии проекта в Visual Studio **обязательно** укажите путь к корневой папке игры в атрибуте `<GameDir>` во всех файлах `.csproj`. После все необходимые Unity и BepInEx сборки подключатся автоматически

[!warging] При передаче атрибута `GameDir` через CLI флаг, **требуется указывать абсолютный путь**. Использование `..\` или прочих относительных путей может привести к ошибке, т.к атрибут влияет и на зависимый проект LegacyUIFramework, находящийся в одной из вложенных директорий.
