# Documentation layout

- Keep all BCL and plugin developer documentation under `docs/<locale>/dev-docs/`.
- Keep player and server-administrator instructions under `docs/<locale>/user-docs/`.
- README and navigation pages may link to developer documents; do not embed API references or build guides there.
- Use the Russian server guide as the source for EN and ZH server guides. Keep configuration examples valid and synchronized.
- Verify public API names, signatures, visibility and behavior against the current C# implementation.
