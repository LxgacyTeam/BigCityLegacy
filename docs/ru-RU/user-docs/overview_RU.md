# Описание

**BigCityLegacy** - проект, целью которого является полное восстановление онлайн Steam-версии игры MadOut2 BigCityOnline для обеспечения оригинального игрового опыта и сохранения истории игры.

Проект представляет собой модификацию для игры и распространяется в виде плагина для BepInEx 5

# Функции и возможности (подробно):

* **Мод убирает обязательную привязку игры к онлайн-серверам** и обеспечивает полную работу в офлайн режиме.
* **Мод позволяет запустить игру в режиме сервера** и **легко подключиться к нему через отдельное меню**. Сервер имеет несколько режимов, гибкую настройку и управление через интерактивный CLI интерфейс (см. подробно в разделе Сервер)
* **Сервер поддерживает все основные игровые режимы** (FreeRoam, RP, Гонки и "Копы против Бандитов").
  *Онлайн-паркур в планах на восстановление в будущих релизах и пока не поддерживается.*
* **Сервер имеет полноценный headless-режим**, не требует графики для запуска и способен работать в Windows или Linux консоли.
* **Сервер имеет CLI интерфейс и система администрирования**: бан и кик игроков, очистка машин и дропа, перезапуск конфигов (см. в разделе Сервер)
* Возможность запуска Mirror сервера для отдачи клиенту списка серверов и их состояния (см. в разделе Сервер).
* **Возможно создание собственных трасс для онлайн-гонок и зон для режима "Копы против Бандитов".**
  Оригинальные так называемые ивенты (т.е. трассы и зоны) полностью утеряны, т.к загружались с сервера и не содержатся в клиенте игры, поэтому загрузка собственных ивентов является обязательным для работы режимов. В текущем релизе представлено лишь несколько ивентов как шаблон для создания своих (см. раздел Создание ивентов).
* Мод использует LegacyUIFramework - собственный фреймворк для создания перетаскиваемых окон и стилизованных UI элементов.
* Все UI элементы мода поддерживают локализацию и реагируют на смену языка в настройках игры
* Мод имеет систему автообновлений (На Windows используется внешний установщик, обеспечивающий автообновление; на остальных платформах используется скачивание zip для ручной установки)
* Мод имеет инструмент Point Tool v2 для удобного создания своих ивентов (создания цепочки координат для чекпойнтов или позиций).
* Мод добавляет несколько горячих клавиш:
  - `F5` - быстрое переключение погоды
  - `F6` - быстрый спавн последнего выбранного авто; в онлайне действует серверный `CarSpawnTimeout`.
  - `F12` - экстренное отключение от сервера (в случаях, если игра зависла на черном экране)
* Мод позволят снять ограничение FPS (ограничение ставится на 10000)
* Мод добавляет возможность включить тень от персонажа (вкл. по умолчанию)

# Параметры запуска

> [!WARNING]
> Начиная с версии 1.4.0, за настройки сервера по умолчанию отвечает файл `ServerConfig.toml`, расположенный в `BigCityLegacy\config`
> См. подробности в соответсвующем разделе: [Описание конфигурации сервера](./server_RU.md)

Мод имеет множество параметров (аргументов запуска), передаваемых запускному файлу игры. Они используются в основном для запуска сервера, но есть параметры и для клиента.

**Аргументы передаются в виде:**

```
game.exe -arg1 -arg2 -arg3
```

Аргументы со значениями используют строгий синтаксис двоеточия:

```text
-key:value
-key:"value with spaces"
```

#### Примеры использования:

Запустить игру, заранее указав игровой сервер:

```
game.exe -connectIP:1.2.3.4 -connectPort:7800
```

Запустить игру, заранее указав mirror сервер:

```
game.exe -useMaster -masterIP:1.2.3.4 -masterPort:35000
```

Запустить **сервер** в режиме base (только game server; `masterServer = false` в TOML):

```
game.exe -bend_GameServer -batchmode -nographics -port:7800 -maxConn:32 -Mode:Race
```

Запустить **сервер** в режиме master (game server + mirror):

```
game.exe -bend_GameServer -batchmode -nographics -port:7800 -maxConn:32 -Mode:Race -masterServer
```

Запустить **сервер** в режиме master с указанием собственных лимитов:

```
game.exe -bend_GameServer -batchmode -nographics -port:7800 -maxConn:32 -Mode:Race -masterServer -maxCars:100 -maxCarsByPlayer:15 -maxNikLength:20 -idleKickTimeout:120s
```

Запустить **сервер** в режиме master, указав собственные файлы с конфигами:

```
game.exe -bend_GameServer -batchmode -nographics -port:7800 -maxConn:32 -Mode:Race -masterServer -serversList:myservers.json -eventsList:myevents.json
```

> [!NOTE]
> Скрипты `runServer.cmd` и `runServer.sh` запускают сервер с обязательными флагами. Параметры задаются в `BigCityLegacy/config/ServerConfig.toml`; другой файл можно передать через `-serverConfig`. [Описание конфигурации сервера](./server_RU.md).

# Режим совместимости

> [!NOTE]
Мод имеет полную поддержку только версии игры `9.4`, которая является последней для Steam.

При запуске на более ранних версиях игры мод запускается в режиме совместимости (Compatibility Mode) и пытается обеспечить их базовую работу (без онлайн-функционала).

> [!WARNING]
> Стабильная работа игры и её офлайн функционала в режиме совместмости **не гарантируется**!

Режим совместимости и поддержку более старых версий игры планируется улучшать в будущем.

# Подключение к серверу

Мод предоставляет несколько официальных публичных серверов, доступных сразу после входа в игру.

Подключиться к стороннему серверу можно через окно **Подключение к серверу**

Имеются 2 вкладки: **Подключение к Master** и **Прямое подключение**

При подключении к Master игра получает с него список серверов и отображает в меню. Адрес и порт сохраняются.

При прямом подключении сразу происходит подключение к игровому серверу по IP и порту. При этом статус онлайна в меню отображаться не будет.

# Источник данных
Мод во время своей работы получает некоторые данные из своего git-репозитория (используется для работы публичных серверов и системы обновлений)
Если GitHub недоступен (актуально для Китая), можно переключить источник данных на зекрало Codeberg.

Переключение осуществляется в окне "О моде" и действует глобально для всех функций.
